# RazorFlow AI - Business Automation Platform

🚀 **Live Demo**: [razorflow-ai.github.io](https://razorflow-ai.github.io)
🔗 **API Backend**: Deployed on Railway

## 🎯 Business AI Suite

RazorFlow AI is a comprehensive business automation platform featuring three specialized AI assistants:

### 🤖 AI Assistants
- **💰 Finance Bot** - Financial analysis, budgeting, and reporting
- **📈 Sales Bot** - Lead management, CRM automation, and sales optimization  
- **📅 Smart Scheduler** - Intelligent appointment scheduling and calendar management

### 🏗️ Architecture
- **Frontend**: React/Vite deployed to GitHub Pages
- **Backend**: FastAPI deployed to Railway
- **Database**: PostgreSQL (Railway managed)
- **AI Models**: OpenAI GPT-4, Google AI, Local LLMs

## 🚀 Quick Start

### Frontend (GitHub Pages)
```bash
npm install
npm run dev          # Development
npm run build        # Production build
npm run deploy       # Deploy to GitHub Pages
```

### Backend (Railway)
```bash
pip install -r requirements.txt
python main.py       # Local development
# Auto-deploys to Railway on git push
```
